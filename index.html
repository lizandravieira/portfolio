About

Who I am

The person behind the code

I'm a junior software engineer at CESAR, in Recife, Brazil. I chose tech because it's the only place I can build without limits - and I haven't stopped since.

Approach

I care about writing code that actually works: clean, reliable, and easy to maintain. Whether it's mobile, embedded, or web, I bring the same mindset: understand the problem deeply before reaching for a solution.

Origin

Started in embedded systems, moved into mobile. That path taught me to think in constraints: power, memory, real-time requirements, before reaching for abstractions.

Learning

Always curious, about code and everything else. I learn best by doing: new projects, new stacks, new problems. The goal is always to get a little better than yesterday.

Beyond

When I'm not coding: watching films and series with friends, baking brownies, exploring new places and restaurants, playing with my dog, and having good conversations. Life is the best context switch.
